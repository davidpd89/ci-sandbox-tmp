# 00_OPERATIVO

Esta carpeta es la puerta de entrada del repo. Si una tarea no puede resolverse leyendo esto y el flujo concreto, el repo sigue desordenado y hay que actualizar esta capa.

## Como usar el repo

1. Leer `01_CONTEXTO_UNICO.md`.
2. Elegir objetivo:
   - Carrusel/post de Instagram: `02_FLUJOS/instagram.md`.
   - Reel/video corto: `02_FLUJOS/video-corto.md`.
   - Imagen o video con IA: `02_FLUJOS/ia-generativa.md`.
   - Musica, voz o subtitulos: `02_FLUJOS/audio-subtitulos.md`.
   - Programar/publicar: **manual/nativamente en cada plataforma**; consultar el `PROCESO.md` de la red. `02_FLUJOS/metricool.md` es solo histórico/retirado.
   - Crecimiento/interacción orgánica: `02_FLUJOS/crecimiento-organico.md` + el `SISTEMA_DIARIO_*/ESTADO.md` de cada red.
   - Dar vida diaria a X (posts + interaccion real, sin parecer bot): `../SISTEMA_DIARIO_X/README.md`.
3. Crear o continuar la prueba en `nuevas ideas rrss/`.
4. Guardar prompts, inputs, outputs y QA en la carpeta de la prueba.
5. Solo despues de revision humana, preparar publicacion.
