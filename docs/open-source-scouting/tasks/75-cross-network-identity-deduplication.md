# Identidad y deduplicacion entre redes

Investigar como reconocer que perfiles de distintas plataformas pertenecen a la
misma persona o proyecto usando enlaces declarados, web, nombre y senales
publicas. Comparar entity resolution y grafos publicos mantenidos.

Crear entidades con nivel de confianza y evidencia. Integrarlas con CRM,
reciprocidad y memoria conversacional para obtener una relacion global, con
fixtures ambiguos y pruebas de fusion y separacion.
