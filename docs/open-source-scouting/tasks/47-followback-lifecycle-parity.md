# Ciclo de followback en todas las redes

Auditar Bluesky, Facebook, Instagram, Mastodon, Pinterest, Reddit, Threads,
TikTok y X para localizar seguimiento, comprobacion de reciprocidad y retirada.
Construir una matriz ejecutable con estados, fuentes de datos y cobertura real.

Crear pruebas con cuentas fixture y relojes controlados que recorran follow,
espera, followback, ausencia de followback y cambio posterior. Corregir gaps y
extraer un componente comun cuando reduzca duplicacion. Medir precision y coste.
