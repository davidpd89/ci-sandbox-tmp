# Automatizacion de navegador y movil

Investigar proyectos publicos de Playwright/CDP/Appium/UIAutomator para ownership
de sesiones, page objects, selectores resilientes, trazas, screenshots, waits,
locks, recuperacion y pruebas visuales.

Elegir una mejora que reduzca flakiness o tiempo en una ruta real del sistema.
Medir antes/despues y reforzar ownership de perfiles, sesiones y dispositivos
para coordinar workers que usan el mismo navegador o telefono.
