# Mutation testing

Investigar herramientas publicas de mutation testing para Python y aplicarlas a
modulos de alto riesgo: ledger, colas, politicas, ejecutores y confirmaciones.

Medir que mutaciones sobreviven y por que. Añadir pruebas que maten mutaciones
con impacto real, priorizando condiciones invertidas, excepciones suprimidas,
estados pendientes tratados como exito y limites temporales. Documentar el
score inicial y el alcanzado tras las mejoras.
