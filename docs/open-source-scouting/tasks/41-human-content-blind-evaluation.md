# Evaluacion ciega de contenido humano

Investigar repositorios publicos de evaluacion de estilo, pairwise ranking,
rubricas, anotacion y deteccion de repeticion.

Construir una evaluacion ciega con ejemplos sinteticos y contenido saneado para
comparar respuestas por contexto, especificidad, naturalidad, variedad y valor
conversacional. Usar resultados para mejorar prompts, memoria y filtros. Separar
claramente preferencias humanas, heuristicas y metricas automaticas.
