# Continuidad de conversaciones

Auditar si cada respuesta conoce el hilo, las interacciones previas y los temas
compartidos con la persona. Investigar memorias conversacionales publicas,
resumen incremental y recuperacion por identidad.

Implementar contexto compacto entre redes y pruebas de conversaciones largas,
ramificadas y reanudadas dias despues. Medir preguntas contestadas, referencias
correctas y numero de intercambios por conversacion.
