# Coste, tokens y llamadas repetidas

Investigar herramientas publicas de tracing, caching, batching, memoization y
presupuestos de coste para agentes y APIs.

Instrumentar una ronda sintetica para contar tokens, llamadas, consultas,
serializaciones y aperturas de navegador. Identificar trabajo repetido y aplicar
una optimizacion medible que conserve calidad y frescura. Añadir presupuestos y
un informe comparativo facil de revisar.
