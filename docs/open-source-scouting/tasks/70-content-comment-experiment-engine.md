# Motor de experimentos de contenido y comentarios

Investigar frameworks publicos de experimentacion secuencial y bandits que
funcionen con muestras pequenas. Compararlos con el tracking actual de posts,
comentarios, hashtags, horarios e imagenes.

Implementar asignacion, exposicion, eventos de resultado y lectura por red.
Crear experimentos iniciales sobre apertura, pregunta, hashtag y contexto, con
tests deterministas y dashboard de aprendizaje acumulado.
