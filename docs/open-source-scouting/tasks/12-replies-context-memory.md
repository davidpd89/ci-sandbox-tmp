# Respuestas humanas, contexto y memoria

Investigar proyectos publicos de memoria conversacional, retrieval, evaluacion
de respuestas, deteccion de repeticion, style guides y human-in-the-loop.

Buscar una pieza que ayude a responder al contenido real, recordar interacciones
previas, evitar cierres artificiales y medir naturalidad sin bancos de frases.
Los datasets deben ser sinteticos o anonimizados. Comparar contra las politicas,
provenance, writer y colas existentes con evaluacion ciega reproducible.
