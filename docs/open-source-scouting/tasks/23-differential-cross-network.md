# Pruebas diferenciales entre redes

Construir una matriz de comportamientos equivalentes y ejecutar los mismos
escenarios sinteticos sobre adaptadores, planners y ejecutores de cada red.
Investigar harnesses publicos de differential testing y contract testing.

Detectar diferencias en estados, retries, deduplicacion, confirmaciones, fechas,
presupuestos y resultados. Convertir cada divergencia injustificada en una
correccion comun o en un contrato explicito de capacidad por plataforma.
