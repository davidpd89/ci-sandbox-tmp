# Drift de APIs y contratos externos

Investigar OpenAPI diff, schema snapshots, mock servers y contract testing
publicos aplicables a Meta, ATProto, Mastodon, Reddit, Pinterest y TikTok.

Capturar respuestas saneadas y contratos relevantes, comparar versiones y
simular campos añadidos, ausentes o con tipos nuevos. Mejorar parsers, paginacion,
errores y compatibilidad. Crear un informe que señale cambios externos con impacto
antes de que rompan una ronda real.
