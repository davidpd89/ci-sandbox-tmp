# Maquina de estados de relaciones

Modelar la vida completa de una relacion: descubierto, candidato, seguido,
reciproco, activo, fiel, inactivo, reactivado y cerrado. Comparar motores de
estado publicos y patrones aplicables al sistema RRSS.

Conectar eventos de todas las redes con transiciones verificables. Incorporar
pruebas generativas de secuencias, persistencia tras reinicio y visualizacion de
estado. Detectar transiciones imposibles y reparar productores inconsistentes.
