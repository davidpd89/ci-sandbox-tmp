# Analitica, atribucion y experimentos

Investigar librerias publicas de funnels, cohortes, UTM, atribucion, tests A/B,
intervalos de confianza y causalidad practica.

Crear o adoptar la pieza minima para relacionar acciones con comunidad, trafico
a la web, ventas o lecturas sin inventar conversiones. Debe distinguir ausencia
de datos, control, madurez, duplicados y fuentes verificadas. Incluir un informe
reproducible que sirva para decidir ademas de acumular metricas.
