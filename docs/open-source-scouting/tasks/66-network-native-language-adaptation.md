# Lenguaje nativo de cada plataforma

Investigar con muestras actuales como difieren longitud, tono, hashtags,
preguntas, saltos de linea, enlaces y llamadas a conversar en cada red. Comparar
estas pautas con los adaptadores y publicaciones del repositorio.

Crear transformadores por plataforma que mantengan la idea y voz original.
Evaluarlos con revisiones ciegas y metricas reales. Incorporar fixtures para
posts, comentarios, respuestas y reposts comentados.
