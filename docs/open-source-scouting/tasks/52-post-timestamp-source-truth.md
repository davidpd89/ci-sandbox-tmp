# Fuente fiable de fecha de publicacion

Comparar timestamps de API, HTML, datos embebidos, interfaz movil y feeds para
cada plataforma. Documentar unidades, timezone, ediciones, reposts, posts
fijados y contenido recomendado antiguo.

Implementar un normalizador con procedencia y confianza. Probar segundos frente
a milisegundos, cambios DST, fechas relativas y campos ausentes. Hacer que cada
decision de interaccion registre la fecha original utilizada.
