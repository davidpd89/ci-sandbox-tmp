# Contenido, media y assets

Investigar herramientas publicas para validacion y transformacion de imagen,
video, alt text, metadatos, aspect ratios, compresion, thumbnails y plantillas.

Buscar una pieza que valide o prepare assets por red sin perder el aspecto humano
ni generar contenido generico. Probar dimensiones, peso, codecs, accesibilidad,
nombres, duplicados y previsualizacion. Debe integrarse con el banco existente y
fallar antes de intentar publicar un archivo incompatible.
