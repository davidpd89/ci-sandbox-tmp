# Pruebas basadas en modelos y maquinas de estado

Investigar Hypothesis stateful y proyectos publicos similares. Modelar el ciclo
planificado, reservado, enviado, pendiente, confirmado, fallido, reconciliado y
reintentado para una accion social.

Generar secuencias largas de eventos, reinicios y respuestas ambiguas. Comparar
el modelo con ledger, colas y ejecutores reales. Corregir transiciones imposibles,
dobles acciones y estados sin salida que aparezcan durante la exploracion.
