# Drift entre capacidades y configuracion social

Comparar lo que cada adaptador implementa con lo que habilitan configuraciones,
jobs, workflows y documentacion. Detectar funciones presentes pero inactivas,
parametros divergentes y defaults que cambian el comportamiento entre redes.

Crear validacion automatica de drift y snapshots de configuracion efectiva.
Homogeneizar nombres y semantica donde aporte claridad y cubrir cada cambio con
tests de carga, precedencia y compatibilidad.
