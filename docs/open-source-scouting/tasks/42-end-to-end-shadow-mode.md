# Simulacion end-to-end y shadow mode

Investigar simuladores, record/replay, digital twins y entornos sandbox publicos.

Crear una ronda completa en shadow mode: descubrir, seleccionar, planificar,
escribir, validar, ejecutar simulado, confirmar, medir y alertar. Reutilizar
respuestas saneadas de plataformas y relojes controlados. El resultado debe
mostrar de extremo a extremo donde se pierde contexto, estado o trazabilidad.
