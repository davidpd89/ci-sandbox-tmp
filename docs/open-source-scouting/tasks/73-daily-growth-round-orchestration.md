# Orquestacion de la ronda diaria de crecimiento

Trazar de extremo a extremo discovery, seleccion, follow, interaccion,
reciprocidad, fidelizacion, limpieza y medicion para cada red. Comparar orden,
dependencias, frecuencia y datos compartidos.

Crear un planificador comun observable con adaptadores por plataforma. Probar
reinicios, rondas solapadas, trabajo parcial y recuperacion. Entregar un resumen
diario que explique acciones, decisiones y resultados.
