# Generacion de fixtures y datos sinteticos

Investigar factories, generadores y estrategias publicas para producir perfiles,
posts, conversaciones, errores y historiales coherentes.

Crear una biblioteca reutilizable de fixtures parametrizados por red, idioma,
edad, relacion y estado. Sustituir duplicacion de tests y ampliar combinaciones
significativas. Medir cobertura de casos y facilidad para reproducir un fallo con
una semilla concreta.
