# Paridad de configuracion y capacidades

Revisar configuraciones, defaults, variables de entorno, flags y matrices de
capacidades de todas las redes. Investigar validadores publicos de configuracion
y feature matrices.

Detectar opciones huérfanas, defaults divergentes, funciones implementadas sin
activar y redes que omiten un control comun. Generar una vista comparativa y
homogeneizar contratos compartidos conservando las diferencias reales de cada
plataforma.
