# Ciclo de vida de interacciones reversibles

Auditar like/unlike, repost/unrepost, follow/unfollow, guardado y acciones
equivalentes en todas las redes. Comprobar confirmacion, retrasos, contadores,
notificaciones y estado tras reinicio.

Implementar un journal comun de intencion y resultado, reconciliacion remota y
tests de reintento. Crear una matriz que muestre acciones reversibles y coste
visual en el perfil o feed para orientar cada estrategia.
