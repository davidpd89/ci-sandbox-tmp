# Deteccion de repeticion y frases prefabricadas

Analizar historicos y colas pendientes para descubrir aperturas, cierres,
preguntas, adjetivos y estructuras repetidas entre redes. Investigar detectores
publicos de similitud semantica, fingerprints y diversidad textual.

Implementar indices de similitud globales y por plataforma, con explicacion del
solapamiento. Generar alternativas desde el corpus propio y añadir pruebas que
midan variedad semanal y mensual.
