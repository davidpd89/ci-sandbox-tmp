# Benchmark de comentarios para todas las redes

Reunir muestras reales y plantillas actuales de cada plataforma. Construir un
benchmark que mida especificidad, naturalidad, aporte, brevedad, curiosidad,
continuidad y adecuacion al post original.

Comparar prompts, modelos y generadores publicos vigentes. Ejecutar evaluacion
ciega humana y automatica, integrar la mejor estrategia por red y crear tests de
regresion con casos de literatura, noticias, premios y conversaciones.
