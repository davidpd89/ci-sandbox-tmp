# Modelo de datos, almacenamiento e informes

Investigar proyectos publicos y librerias para eventos tipados, SQLite/DuckDB,
Parquet, migraciones, validacion de esquemas, lineage e informes reproducibles.

Comparar con CSV, JSON y SQLite actuales. Probar una mejora minima que facilite
consultas y comparativas entre redes sin migracion total ni perdida de datos.
Debe manejar versiones, concurrencia, corrupcion, exportacion, privacidad y una
ruta clara de rollback.
