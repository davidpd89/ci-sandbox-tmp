# Fugas de recursos y ciclo de vida

Investigar herramientas publicas para detectar fugas de procesos, handles,
archivos, sockets, SQLite, Playwright, CDP y memoria.

Ejecutar rondas repetidas y escenarios de excepcion, midiendo recursos antes y
despues. Revisar context managers, finally, shutdown y ownership. Corregir fugas
reproducibles y añadir pruebas que funcionen en Windows y Linux.
