# Matriz ejecutable de paridad entre redes

Convertir la lista de funcionalidades sociales en contratos ejecutables para
Bluesky, Facebook, Instagram, Mastodon, Pinterest, Reddit, Threads, TikTok y X.
Incluir discovery, follow, unfollow, like, comentario, repost y fidelizacion.

Generar la matriz desde capacidades reales del codigo y ejecutar smoke tests por
adaptador. Cada celda debe enlazar implementacion, pruebas, configuracion y
metricas para descubrir gaps automaticamente.
