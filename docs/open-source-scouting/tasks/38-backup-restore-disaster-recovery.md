# Backup, restore y recuperacion operativa

Investigar herramientas y patrones publicos para snapshots consistentes,
backups incrementales, verificacion y restauracion de SQLite, CSV, JSON y media.

Definir escenarios de perdida o corrupcion y ensayar restauraciones completas en
un directorio temporal. Medir RPO/RTO practicos, integridad y compatibilidad de
versiones. Automatizar la verificacion periodica y documentar el procedimiento
ejecutable.
