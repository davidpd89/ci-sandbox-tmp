# Comentarios anclados al contexto real

Auditar cuantos comentarios usan texto, imagen, autor, hilo, fecha y contexto
previo del post. Investigar pipelines multimodales y RAG conversacional publicos
que puedan mejorar la comprension antes de escribir.

Crear un paquete de contexto comun por plataforma y tests que relacionen cada
frase con evidencia del contenido. Medir respuestas recibidas, continuidad y
valor percibido frente al generador actual.
