# Descubrimiento de grupos, comunidades y nichos

Mapear grupos, comunidades, subreddits, feeds, listas, starter packs, tableros,
servidores, topics y superficies equivalentes de todas las plataformas.
Investigar repositorios que cataloguen o descubran estas estructuras.

Crear un registro comun con audiencia, actividad, afinidad, reglas, URL y ultima
revision. Implementar recolectores disponibles, ranking y pruebas de refresco.
Entregar candidatos concretos para literatura, libros y cultura.
