# Agentes, skills y orquestacion

Investigar frameworks y repositorios publicos de agentes, skills, tool calling,
state machines, evaluaciones, checkpoints y aprobacion humana.

Comparar con los scripts y prompts actuales. Reutilizar piezas que hagan
mas determinista el flujo investigar-planificar-escribir-validar-publicar o que
reduzca tokens y repeticion. Comparar frameworks completos y componentes simples
por valor, coste y mantenibilidad. Incluir trazabilidad de decisiones y herramientas.
