# Unicode, locale y codificacion

Investigar herramientas publicas de fuzzing Unicode, normalizacion, confusables,
CSV dialects y encoding detection.

Probar nombres, textos, URLs, hashtags y archivos con tildes, emoji, RTL,
caracteres combinados, BOM y saltos de linea de Windows/Linux. Corregir perdida,
duplicacion o comparaciones inconsistentes y consolidar helpers compartidos con
fixtures legibles.
