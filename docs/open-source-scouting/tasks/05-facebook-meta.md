# Facebook

Investigar SDK y ejemplos publicos de Graph API para paginas, publicaciones,
comentarios, reacciones, inbox, webhooks, insights, tokens y media.

Auditar `facebook_*` y `meta_*` frente a soluciones mantenidas. Buscar mejoras
para comentarios entrantes, confirmacion de acciones, paginacion, errores,
analitica y renovacion segura de credenciales. Comparar permisos, tipos de cuenta
y alcance funcional para escoger la integracion que aporte mas valor.
