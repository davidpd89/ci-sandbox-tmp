# Calidad de datos y reconciliacion

Investigar frameworks publicos de data quality, expectations y reconciliation.

Definir invariantes para acciones, metricas, cohortes, contenidos, fuentes y
estados. Buscar duplicados, fechas imposibles, contadores incompatibles, claves
huérfanas y confirmaciones sin procedencia. Crear un reporte accionable y reparar
el pipeline que origine al menos una inconsistencia reproducible.
