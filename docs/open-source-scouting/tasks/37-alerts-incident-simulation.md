# Calidad de alertas y simulacion de incidentes

Investigar proyectos publicos de alert testing, SLO, deduplicacion, routing y
runbooks accionables.

Simular caidas, workers detenidos, colas estancadas, tokens caducados, cero actividad y
degradacion parcial. Medir precision, ruido, latencia y contexto de cada alerta.
Mejorar codigos, severidad, agrupacion y mensajes para que cada aviso conduzca a
un diagnostico o accion concreta.
